# Language Resources

Canonical recommendations are built in the validated knowledge language before any
translation or speech synthesis. Translation and TTS are provider boundaries under
`integrations/`.

Provider-specific glossaries or reviewed terminology files may be added here. They
must be versioned and reviewed by Developer 2/agronomy-language reviewers. Do not
place agricultural decision thresholds or executable code in language files.

The V1 development adapter is pass-through English. Configure a real translator and
TTS provider at the composition root only after privacy, credentials, timeout, and
quality policies are approved.
