# Référentiel des Ressources Photographiques et Visuelles

Ce dossier organise les ressources photographiques de la base de connaissances conformément à la Section 9 du document `Structure_des_connaissances_agricoles_Cameroun.pdf`.

## Organisation des Dossiers
- `sols/` : Profils de sols, fosses pédologiques, couleurs d'horizons.
- `textures_structures/` : Échantillons de textures au doigt (boudin), structures grumeleuses, encroûtements.
- `pratiques_agricoles/` : Billonnage selon courbes de niveau, buttage, tuteurage, effeuillage, paillage.
- `engrais_equipements/` : Sacs et aspects d'engrais (NPK, urée, chaux), compostière, pulvérisateur.
- `cultures_stades/` : Pépinière, reprise, floraison, grossissement, récolte de tomate, pomme de terre, etc.
- `relief_topographie/` : Versants de l'Ouest, terrasses des Monts Mandara, bas-fonds aménagés.

## Métadonnées
Toutes les photos sont indexées dans `metadata_catalogue.json` avec :
- Titre
- Description
- Catégorie
- Culture concernée
- Région / Localité
- Date
- Source et Droits
- Entité / Code associé dans la base de connaissances
